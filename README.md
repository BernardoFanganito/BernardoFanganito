## 🚀 Projetos

### [BY Support](https://github.com/BernardoFanganito/BY-Suport)
> Extensão Chrome que automatiza fluxos de suporte entre Octadesk, Bling e Slack

Reduziu o tempo de registro de atendimentos de **~70 segundos para ~15 segundos** e de **18–25 cliques para 2–4 cliques** por atendimento. Integra IA (Gemini) para analisar conversas e estruturar os dados automaticamente.

`JavaScript` `Chrome Extension MV3` `Gemini AI` `Service Worker`

---

### [Plan & Execute](https://github.com/BernardoFanganito/plan-and-execute)
> App mobile de produtividade pessoal com treinos, afazeres e lembretes

Desenvolvido do zero com React Native e Expo. Notificações locais agendadas, persistência de dados no dispositivo e suporte a iOS e Android.

`React Native` `Expo` `AsyncStorage` `Notificações locais`
